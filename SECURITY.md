# Security Policy

  ## Reporting a Vulnerability

  Please do not report security vulnerabilities through public Issues or pull requests.

  Use GitHub's private vulnerability reporting or Security Advisory feature:

  https://github.com/congress-data-lab/Committee-Steward/security/advisories/new

  Please include:
  - affected version or commit
  - steps to reproduce
  - potential impact
  - any suggested mitigation

  ## Supported Versions

  The latest published release is the supported version. Older releases are not guaranteed to receive
  security fixes.
